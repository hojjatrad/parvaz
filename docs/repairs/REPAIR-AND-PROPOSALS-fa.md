# پرواز — وضعیت اصلاح ممیزی و پیشنهادهای تکمیلی

## نتیجهٔ فعلی

اصلاحات کد برای ۱۱ یافتهٔ اصلی روی شاخهٔ جداگانهٔ `fix/audit-repairs` پیاده شده‌اند. نامزد بعدی **1.28.6 / کد 40** است؛ **هنوز منتشر نشده** و نسخهٔ پایدار **1.28.5**، تگ‌ها، اطلاعات کاربر و کلید امضای نسل سوم دست‌نخورده‌اند.

این گزارش به معنی رفع تأییدشدهٔ همهٔ شرایط روی گوشی یا آماده‌بودن APK انتشار نیست. هیچ merge یا انتشار خودکاری انجام نشده است.

### ریسک‌های جانبی که کدشان نیز بهبود یافت

- صف پینگ ظرفیت‌دار است؛ نتیجهٔ سلامت جای تست دستیِ درحال‌اجرا را نمی‌گیرد.
- پینگ ذخیره‌شده بدون شاهد تازه، «تست قبلی» است؛ نمونهٔ جلسهٔ جاری اطلاعات نوع/مقصد در صورت ثبت، زمان و اعتبار شبکه دارد. مقصد ثبت‌نشده صریحاً نامشخص می‌ماند.
- آزمون‌های Fragment از snapshot تنظیمات استفاده می‌کنند، نه تغییر موقت تنظیمات سراسری؛ ذخیرهٔ برنده نیازمند تأیید و معتبرماندن منبع/پروفایل/شبکه/تنظیمات است.
- ورودی فایل مهلت ۲۰ثانیه‌ای، محدودیت حجم و حداکثر دو خوانندهٔ مسدود دارد؛ provider بدرفتار نمی‌تواند بی‌نهایت thread بسازد.
- GitHub Actions به SHA پین شدند و پیکربندی بازبینی وابستگی‌ها اضافه شد؛ این **جایگزین SBOM کامل یا اسکن جامع CVE نیست**.

## شواهد آزمون

- در commit `9e94b3f`: **۵۵۶ تست واحد، صفر شکست/خطا/skip**؛ شامل ۴۶ اجرای آزمون‌های جدید اصلاح ممیزی. Build debug و R8 نیز در همان گردش موفق بودند.
- **۳۰۴ assertion میزبان** و **۳۶ آزمون Python** در اجرای محلی موفق شدند.
- **۶ assertion سیاست مقصد** با transport جانشین موفق شدند؛ HTTPS واقعی گوشی محسوب نمی‌شوند.
- parser واقعی: GeoIP همراه برنامه ۵ tag، GeoSite همراه ۳ tag؛ جفت رسمی پین‌شده به‌ترتیب ۲۷۸ و ۱۵۴۷ tag معتبر داشتند.
- آزمون ابزار Android آرشیو/رمزگذاری/بازیابی: **۱۱ تست در هرکدام از SDK29 و SDK34** موفق؛ این ابزار جدا از کل برنامهٔ VPN است.
- پس از این commit، بررسی دوبارهٔ قفل برای عملیات تأخیری نیز سخت‌گیرانه‌تر شده است؛ نتیجهٔ commit قبلی را به‌جای نتیجهٔ تغییر جدید حساب نمی‌کنیم.

### مواردی که هنوز مانع اعلام پایان کامل‌اند

1. گیت lint/بسته‌بندی/امضای نامزد باید کامل موفق شود؛ علت توقف lint، نوشتن مقدار عددی به‌جای ثابت نام‌دار نوع احراز هویت بود و در کد اصلاح شد. این شکست مربوط به کلید امضا نبود.
2. تست پروتکل‌های واقعیِ host برای Hy2، TUIC و full-clash موفق بود؛ گیت native در اجرای Android helper متوقف شد و نتیجهٔ نهایی موفق ندارد. ثبت تشخیص دقیق‌تر و اجرای دوباره لازم است.
3. SBOM و SCA جامع وابستگی‌های Java/Go هنوز انجام نشده؛ پین Actions فقط بخشی از ریسک زنجیرهٔ تأمین را کاهش می‌دهد.
4. آزمایش واقعی نصب و ارتقا، VPN/DNS/IPv6، خاموشی صفحه، Doze، باتری و تغییر Wi-Fi/دیتا **NOT_RUN** است. نبود دستگاه از قبل مشخص است و درخواست مجدد دسترسی نمی‌کنیم.
5. مسیر آزمایشگاهی DNS همچنان **PROMOTION_BLOCKED** است؛ UNKNOWN را به «بدون نشت» تبدیل نکرده‌ایم.

## پیشنهادهای تازه — فقط برای بررسی شما

این موارد با عنوان قابلیت جدید اجرا نشده‌اند:

1. **صفحهٔ توضیح وضعیت اتصال:** یک صفحهٔ ساده که جداگانه نشان دهد تونل روشن است، پاسخ HTTPS دیده شده، پینگ مربوط به کدام تست است و چرا بعضی بخش‌ها «نامشخص» هستند.
2. **پیش‌نمایش گزارش پیش از اشتراک‌گذاری:** امکان دیدن و حذف بخش‌های گزارش به‌صورت محلی؛ ارسال فقط با انتخاب صریح کاربر، بدون گزارش خودکار.
3. **پشتیبان رمزدار پیش از ارتقا:** گزینهٔ اختیاری برای گرفتن نسخهٔ قابل‌بازیابی از داده‌ها پیش از نصب آپدیت؛ بدون ادعای بازگشت خودکار APK در Android.
4. **ماتریس سازگاری دستگاه‌ها:** ثبت نتیجهٔ تست‌های واقعی روی Android و سازندگان مختلف، بدون ذخیرهٔ لینک یا رمز سرورها؛ وقتی امکان آزمایش فراهم شد.

5. **بازآرایی تدریجی کلاس‌های بزرگ:** کوچک‌کردن MainActivity و جداسازی مسئولیت‌های باقی‌مانده، مرحله‌به‌مرحله و با حفظ تست‌ها؛ بدون تغییر ظاهری یا رفتاری ناخواسته.
