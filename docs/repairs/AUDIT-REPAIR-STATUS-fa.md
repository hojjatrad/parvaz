# نامزد اصلاح ممیزی — منتشر نشده

این شاخه تنها برای بررسی/آزمون است؛ نسخهٔ پایدار 1.28.5 را جایگزین نکرده است. merge یا انتشار خودکار مجاز نیست.

- کنترل ویجت private، رنگ موفق وابسته به مدرک HTTPS.
- قفل fail-closed مشترک Activityها، بازقفل هنگام پس‌زمینه و تعویق ورودی حساس تا احراز هویت.
- IP تمیز: حذف عمل همگانی، انتخاب یک TLS/CDN از منبع فعال، preview و probe قبل از commit، undo مشروط. Reality/TLS مستقیم و بایگانی تغییر نمی‌کنند.
- Geo: parser ساختاری محدود، hash رسمی asset و دو فایل یک نسل، نگه‌داشتن فایل‌های فعلی، فعال‌سازی نسل جدید در process بعدی.
- گزارش لاگ/کرش پوشانده می‌شود؛ حجم و زمان مستقل و انقضای دقیق.
- SSID با مجوز آگاهانه و مقایسهٔ دقیق؛ بدون مجوز مکان پس‌زمینه. قواعد شبکه observer مستقل از UI دارند؛ شروع ممنوع در پس‌زمینه با اعلان نیازمند لمس جایگزین می‌شود، نه دورزدن Android.
- تست مقصد strict-target؛ صف پینگ ظرفیت‌دار؛ سلامت نتیجهٔ تست دستی درحال‌اجرا را نمی‌پوشاند.

وضعیت: تغییرات در دست بررسی/تست‌اند. تست گوشی، نصب، دو APK، نشت و باتری NOT_RUN. موارد R02/R03/R06/R08/R09 ممیزی و گیت‌های کامل هنوز بسته نشده‌اند. این سند اعلام رفع کامل نیست.
