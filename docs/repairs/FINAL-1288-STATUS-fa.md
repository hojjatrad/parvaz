# آماده‌سازی انتشار اصلی۱٫۲۸٫۸

## تأیید تازهٔ مالک
مالک اعلام کرد مشکل پینگ حل شده و نسخهٔ اصلی را برای انتشار در GitHub خواست. این نتیجه در `OWNER-PING-ACCEPTANCE-1287.json` ثبت شده است؛ نتیجهٔ آزمون‌های دیگری که گزارش نشده‌اند به آن نسبت داده نمی‌شود.

## انجام‌شده
- نامزد اصلی۱٫۲۸٫۸/کد۴۲ از کد تعمیر پینگ ساخته شد؛ نام برنامه عادی است و برچسب TEST ندارد.
- ترتیب نسخه اجازهٔ ارتقا از۱٫۲۸٫۷ آزمایشی/کد۴۱ را می‌دهد؛ کلید دائمی تغییر نکرده است.
- همان مسیر سخت‌گیرانهٔ اعتبارسنجی نسخهٔ نهایی برای شاخهٔ `release/final-1288` فعال شد. این مسیر به‌خودی‌خود هیچ نسخه‌ای را منتشر نمی‌کند.
- یادداشت انتشار و کد نامزد برای GitHub آماده شده‌اند. تگ نهایی هنوز ساخته نشده است.

## مانع باقی‌مانده
**انتشار نهایی همچنان BLOCKED است؛ آماده‌شدن کد به معنی انتشار APK اصلی نیست.**
بررسی نسخهٔ آزمایشی۱۲ مختصات وابستگیِ حاضر در باینری یا مبنای محافظه‌کارانهٔ فورک را نیازمند بررسی دانسته است. این‌ها لزوماً۱۲ آسیب‌پذیری قابل‌استفاده نیستند، اما هنوز شواهد کافی برای کنارگذاشتن هشدارها وجود ندارد.
آخرین نسخه‌های رسمی دوباره بررسی شدند: Xray wrapper26.9.9، sing-box1.14.1 و Mihomo1.19.31. تعویض بی‌بررسی نسخهٔ هسته، رفع قطعی این هشدارها نیست؛ نسخه‌های جدید فقط با بررسی و آزمون قابل پذیرش‌اند.
اسکن دقیق نامزد، سپس امضا و آزمون نصب APK نهایی لازم‌اند. نگهبان‌های فعلی، دریافت نتیجهٔ مثبت پینگ را به‌جای این مراحل قبول نمی‌کنند و تضعیف نشده‌اند.
