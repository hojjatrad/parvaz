# پرواز ۱.۲۸.۳ — اصلاح تست و نمایش تأخیر

- تست تکی، گروهی و HTTPS دستی از صف مشترک محدود استفاده می‌کنند؛ اشغال ظرفیت نباید کانکشن‌های انتهای صف را بی‌صدا حذف کند.
- عدد میلی‌ثانیه فقط برای پاسخ واقعاً اندازه‌گیری‌شده نمایش داده می‌شود. «تست تأخیر»، «در حال تست»، «تأیید نشد»، «ناموفق»، «مشغول» و «لغو شد» جدا هستند؛ نتیجهٔ نامشخص به قطع بودن سرور تعبیر نمی‌شود.
- لغو گروهی ردیف‌های منتظر را از حالت انتظار خارج می‌کند. نتیجهٔ دیررس، تست تازه‌تر یا نمونهٔ تأییدشدهٔ اتصال زنده را بازنویسی نمی‌کند؛ تغییر شبکه/پروفایل/منبع هم نتیجهٔ قبلی را بی‌اعتبار می‌کند.
- ذخیرهٔ تأخیر دیگر باعث بازنویسی اشتراک و تغییر revision آن نمی‌شود؛ ردیف تازه‌شده «در حال تست» قدیمی را به ارث نمی‌برد.
- حذف کانکشن‌های ناموفق فقط نتیجهٔ ناموفق را در نظر می‌گیرد، نه کانکشن تست‌نشده یا تأییدنشده.
- TLS، تأیید مسیر remote، تاریخچه/انتخاب منبع و امضای دائمی تغییر نکرده‌اند. تغییرات DNS آزمایشگاهی وارد این APK نشده‌اند.

این اعداد تأخیر درخواست HTTPS از مسیر پروکسی‌اند، نه ICMP یا تضمین سرعت دانلود. پیکربندی کاملِ مبهم ممکن است همچنان «تأیید نشد» بدهد؛ عدد ساختگی یا fallback مستقیم اضافه نشده است. اتصال VPN به‌تنهایی پینگ همهٔ کانکشن‌ها را اندازه نمی‌گیرد.

**وضعیت قبل از انتشار:** نامزد اصلاح؛ انتشار فقط پس از موفقیت گیت‌های ساخت، رگرسیون، بسته‌بندی و امضای ثابت. تست نصب/عملکرد روی گوشی کاربر، نشت/Doze/باتری انجام نشده است. از پاک‌کردن داده یا حذف نسخهٔ نصب‌شده خودداری کنید.
