# نسخه ۱.۳۵.۱ (versionCode 52)

## چرا این نسخه
گزارش کاربر: «هنگام به‌روزرسانی، ارتباط برقرار نمی‌شود و شکست می‌خورد.» علت ریشه‌ای پیدا شد و هر دو بخشش اصلاح شد.

## علت (VERIFIED)
به‌روزرسانی فقط از یک مسیر می‌آمد: `https://api.github.com/repos/hojjatrad/parvaz/releases/latest`.
این API برای درخواست‌های بدون توکن سقف **۶۰ درخواست در ساعت به ازای هر آدرس IP مبدأ** دارد. وقتی ده‌ها کاربر از پشت **یک IP خروجی مشترک** (سرور VPN، CGNAT اپراتور) رد می‌شوند، این سهمیه مدام تمام می‌شود و پاسخ **HTTP 403** برمی‌گردد — بدون اینکه هیچ ایرادی در گوشی یا اشتراک شما باشد. علاوه بر این، در بعضی شبکه‌ها `api.github.com` مسدود است در حالی که فایل‌های خود ریلیز قابل دریافت‌اند.

نکتهٔ دوم: ترافیک خودِ برنامه فقط وقتی از تونل عبور می‌کند که تونل **روشن** باشد (`AppNetwork`: با تونل روشن از پراکسی محلی، با تونل خاموش از شبکهٔ سیستم). پس به‌روزرسانی با تونل خاموش روی شبکهٔ فیلترشده طبیعتاً شکست می‌خورد، ولی برنامه این را نمی‌گفت.

## چه چیزی اصلاح شد
۱. **مسیر دوم برای به‌روزرسانی (بدون سهمیهٔ API).** اگر API شکست بخورد (۴۰۳ سهمیه، مسدودی، تایم‌اوت)، برنامه حالا فایل **`SHA256SUMS.txt`** آخرین ریلیز را می‌خواند — که یک فایل معمولی ریلیز است و هیچ محدودیت سهمیه‌ای ندارد — و همان اطلاعات را بازمی‌سازد: نسخه از نام فایل، **هش SHA-256 از خود همان فایل**، و نشانی دانلود از مسیر قطعی ریلیز. اندازهٔ فایل با یک درخواست `HEAD` از خود فایل گرفته می‌شود.

   **هیچ بررسی‌ای سست نشده است:** هش کماکان قبل از نصب بررسی می‌شود، گواهی امضای APK کماکان باید دقیقاً برابر کلید generation3 باشد، و دامنهٔ مجاز دانلود همان `github.com/hojjatrad/parvaz/releases/download/v<version>/` است. اگر فایل چک‌سام نسخه‌های درهم داشته باشد یا هش ناقص/دست‌کاری‌شده باشد، به‌جای حدس زدن **رد می‌شود** (۵ تست واحد تازه در `UpdateFallbackTest` همین را تضمین می‌کند).

۲. **پیام خطای گویا.** اگر به‌روزرسانی شکست بخورد و تونل خاموش باشد، حالا صریح می‌گوید: «تونل خاموش است، پس این درخواست از اینترنت معمولی شما رفت. اول به یک سرور وصل شوید و بعد دوباره به‌روزرسانی را بررسی کنید.» و کد خطای واقعی (HTTP، تایم‌اوت، TLS) هم در همان کادر دیده می‌شود. وقتی هر دو مسیر شکست بخورند، گزارش هر دو خطا را نشان می‌دهد (`…; SUMS …`).

## آنچه تغییر نکرد
مسیر اول همچنان همان API است؛ مسیر دوم فقط وقتی امتحان می‌شود که اولی شکست بخورد. اگر API بگوید «نسخهٔ جدیدی نیست»، همان پذیرفته می‌شود و درخواست دومی فرستاده نمی‌شود.
