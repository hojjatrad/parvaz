# Parvaz 1.28.0 — محدودکردن اعتبار سلامت به شبکه و DNS فعلی

versionCode 34؛ نام بسته و گواهی دائمی تغییر نمی‌کنند. این نسخه APK جداگانه است؛ نسخهٔ 1.27.0 بازنویسی نمی‌شود.

## تغییرات

- پاسخ HTTPS قدیمی پس از تغییر شبکه، قطع/برگشت آن یا تغییر LinkProperties دیگر تأیید شبکهٔ جدید محسوب نمی‌شود. نتیجهٔ رقابت سرورها نیز باید به revision و context فعلی تعلق داشته باشد؛ نتیجهٔ منسوخ برنده یا شکست جدید ثبت نمی‌شود.
- تأیید ارتباط حداکثر دو دقیقه اعتبار دارد؛ سن مدرک با elapsedRealtime، شامل خواب دستگاه، محاسبه می‌شود. در تیک سلامت، از حدود یک دقیقه درخواست تجدید می‌شود، حتی اگر RX دیده شده باشد. RX و نتیجهٔ UNKNOWN اعتبار HTTPS را تمدید نمی‌کنند. زمان اجرای تیک تابع تنظیمات/Android است؛ این به معنی wakeup دقیق یا تضمین پاسخ دقیقه‌ای نیست. انقضای مدرک، تونل را به‌تنهایی قطع نمی‌کند.
- تغییر DNS، دامنهٔ جستجو و Private DNS روی همان شبکه نیز تشخیص داده می‌شود. آدرس‌ها/نام‌های DNS فقط در حافظه مقایسه می‌شوند و در گزارش ذخیره نمی‌شوند.
- در تغییر شناخته‌شدهٔ سیاست resolver، هسته دوباره ساخته می‌شود تا cache قدیمی به سیاست جدید تحمیل نشود. این کار می‌تواند سوکت‌های موجود را قطع کند. با سیاست resolver ثابت و پاسخ معتبر، نمونهٔ زنده همچنان قابل حفظ است.
- تغییر موقت وضعیت اعتبارسنجی Private DNS با همان resolver، نیازمند بررسی دوباره است نه بازسازی cache؛ تغییر نام resolver یا فهرست DNS از این حالت جداست.
- handoverهای نزدیک، هنگام اندازه‌گیری در یک درخواست معوق ادغام می‌شوند؛ صرف مشغول‌بودن پروب موجب reconnect فوری نمی‌شود. UNKNOWN مدرک شکست نیست. تغییر DNS حین اتصال نیز برای رسیدگی بعدی نگه داشته می‌شود.

## محدودیت‌ها

این نسخه **انتقال کش DNS بین موتورهای مختلف را پیاده نمی‌کند**. فرمت، مالکیت resolver، TTL باقی‌مانده و split-DNS در هسته‌ها یکسان نیستند؛ کپی‌کردن فایل/cache بدون قرارداد سازگار ایمن نیست. cache داخلی خود هسته حفظ یا با بازسازی هسته دور انداخته می‌شود. زمان مستقل درخواست DNS همچنان NOT_INSTRUMENTED است.

تغییر معنای DNS بدون تغییر قابل مشاهدهٔ تنظیمات سیستم الزاماً قابل تشخیص نیست. این کنترل جای مدیریت TTL در هسته و آزمون شبکهٔ واقعی را نمی‌گیرد. تست گوشی، باتری، Doze، نشت، DNS/IPv6، handover و نصب کاربر NOT_RUN باقی می‌ماند؛ شبیه‌ساز تست گوشی کاربر نیست.

بروزرسانی شش‌ساعتهٔ هسته‌ها، دانلود اختیاری، نصب با تأیید کاربر، منبع فعال و پشتیبان رمزگذاری‌شده حفظ می‌شوند. پیش از ارتقا پشتیبان بگیرید؛ برنامه و داده‌ها را حذف نکنید.
