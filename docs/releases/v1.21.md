# Parvaz 1.21 — گزارش ساب و به‌روزرسانی Xray

با همان کلید دائمی نسخه‌های 1.19.1 و 1.20 امضا شده است. برای نصب روی این نسخه‌ها برنامه را حذف نکنید. نصب نهایی به تأیید Android نیاز دارد.

## ساب و فهرست سرورها

- نتیجهٔ صفر دیگر به‌عنوان موفقیت بی‌توضیح تمام نمی‌شود؛ گزارش ماندگار شامل تعداد دریافت/تشخیص/افزودن و کد خطا نمایش داده می‌شود.
- در منوی افزودن، «گزارش آخرین افزودن» و «کپی گزارش امن» اضافه شد. گزارش نه URL، نه توکن، نه بدنهٔ خصوصی پاسخ را ذخیره می‌کند.
- بعد از واردکردن موفق، صفحهٔ سرورها خودکار باز می‌شود.
- پاسخ JSON رشته‌ای، Base64 در JSON و فیلد links رشته‌ای پشتیبانی می‌شوند. نشانه‌های نامرئی ابتدا/انتهای لینک و پوشش متداول نقل‌قول/کد پاک‌سازی می‌شوند؛ توکن داخل URL دست‌کاری نمی‌شود.
- اگر فرمت اولیه خالی یا غیرقابل‌شناسایی باشد، همان URL با حداکثر سه قالب سازگار v2rayNG/Clash/Sing-box درخواست می‌شود. خطای TLS، ورود یا محدودیت درخواست دور زده نمی‌شود؛ مسیر URL حدس زده نمی‌شود.

**مورد خصوصی کاربر هنوز بازتولید نشده است.** این تغییرات شکاف‌های مشخص قالب و گزارش‌دهی را پوشش می‌دهند. اگر ساب شما باز هم صفر بود، متن «گزارش آخرین افزودن» را بفرستید، نه لینک خصوصی.

## هسته و آپدیت

- AndroidLibXrayLite از v26.7.31 به **v26.9.9** ارتقا یافت؛ artifact رسمی با SHA-256 ثبت‌شده بررسی می‌شود.
- گردش‌کار روزانهٔ GitHub نسخهٔ رسمی جدید هسته را بررسی می‌کند. فقط پس از موفقیت تست‌ها، ساخت release و بررسی امضا/بسته، نسخهٔ patch جدید با versionCode بالاتر منتشر می‌شود. هیچ کلید تازه‌ای ساخته نمی‌شود.
- هسته داخل APK است، نه فایل قابل تعویض بدون نصب. آپدیت هسته از طریق آپدیت امضاشدهٔ برنامه دریافت می‌شود؛ نصب خودکارِ بدون رضایت Android وعده داده نمی‌شود.
- بررسی خودکار نسخه پس از بازبودن برنامه فعال شد؛ خطاهای بررسی/دانلود دارای تلاش مجدد و لینک صفحهٔ رسمی‌اند. لمس متن نسخه در تنظیمات، توضیح آپدیت هسته و دکمهٔ بررسی را نشان می‌دهد.

زمان‌بندی GitHub، شبکه، مجوزهای مخزن و نتیجهٔ تست‌ها می‌توانند انتشار را به تأخیر بیندازند. آزمون خودکار جایگزین آزمون اتصال واقعی روی گوشی نیست.
