# Parvaz 1.27.0 — کیفیت تطبیقی و بروزرسانی آزموده‌شدهٔ هسته‌ها

versionCode 33؛ بسته و کلید امضای دائمی تغییر نمی‌کنند. نسخه‌های قبلی بازنویسی نمی‌شوند.

## پایداری و انتخاب سرور

- پاسخِ کند، قطعی محسوب نمی‌شود. خرابی باید چند بار با HTTPS از مسیر تأییدشده بررسی شود. وضعیت سبز پس از خرابی تأییدشده پس گرفته می‌شود و با پاسخ معتبر همان نشست قابل بازیابی است.
- جایگزین با موتور واقعی و دو پاسخ معتبر آزمایش می‌شود؛ حداکثر دو نامزد خودکار، سقف عمومی سه اندازه‌گیری و شش worker شبکهٔ زنده. پنجرهٔ مقایسهٔ کوتاه، سابقهٔ محلی و نوسان در امتیاز لحاظ می‌شوند؛ اولین پاسخ به‌تنهایی برنده نیست.
- تعویض صرفاً برای کیفیت به حداقل 25٪ و 100ms بهبود، چند مشاهده، عمر کافی اتصال و فاصلهٔ پنج‌دقیقه‌ای نیاز دارد. هنگام ترافیک مشاهده‌شده، جستجوی کیفیتی عقب می‌افتد. نامزدهای ناموفق واقعی cooldown می‌گیرند؛ موارد تست‌نشده/لغوشده/مبهم شکست سرور حساب نمی‌شوند. پس از دور بی‌نتیجهٔ مبهم، ترتیب بررسی موقتاً می‌چرخد تا سایر نامزدها هم نوبت بگیرند.
- نیافتن جایگزین، تونل قابل استفاده را بی‌دلیل متوقف نمی‌کند. تلاش‌های بازیابی با فاصلهٔ 30 ثانیه تا پنج دقیقه انجام می‌شوند. تنها منبع فعال، با fingerprint فعلی، مجاز است.
- تغییر شبکه ابتدا روی اتصال زنده بررسی می‌شود؛ اگر هنوز پاسخ می‌دهد، هسته و cache آن حفظ می‌شوند. در غیر این صورت reconnect انجام می‌شود. انتقال cache بین دو نمونهٔ native پیاده نشده و انتظار 300ms حذف نشده است.
- منابع موتور خارجی و ظرفیت آن تنها پس از خروج واقعی فرایند آزاد می‌شوند؛ انتظار خروج به reaper پس‌زمینه منتقل شده است. حذف همهٔ ANRها یا قطع‌نشدن همهٔ نشست‌ها ادعا نمی‌شود.

## نگهداری هر سه هسته

پایش نسخه‌های stable رسمی Xray/AndroidLibXrayLite، sing-box و Mihomo هر شش ساعت انجام می‌شود. نسخهٔ جدید فقط پس از کنترل commit/hash، ساخت و آزمون‌ها قابل انتشار است. native TCP/UDP/TLS، شبیه‌ساز Android 10/14، آزمون‌های واحد، lint و بسته‌بندی در مرحلهٔ بدون کلید امضا اجرا می‌شوند.

امضای APK آماده روی runner جداگانه انجام می‌شود؛ باینری نامزد و Gradle روی runner امضاکننده اجرا نمی‌شوند. metadata مستقلاً بازتولید، tree سورس با نامزد آزموده‌شده تطبیق، امضا/بسته/نسخه/ABI بررسی، و rollback هر سه هسته رد می‌شود. source متناظر همراه انتشار است؛ خطای تست/ساخت/مجوز GitHub مانع انتشار می‌شود. برنامهٔ زمانی GitHub تضمین اجرای لحظه‌ای نیست.

## بروزرسانی داخل برنامه

دو کنترل در تنظیمات اضافه شده: بررسی خودکار و دانلود خودکار روی شبکهٔ unmetered هنگام شارژ. بررسی تقریباً هر شش ساعت است؛ زمان‌بندی تابع اندروید/Doze است. دانلود با فضای کافی، بررسی هش/بسته/نسخه/امضا و ادامهٔ دانلود انجام می‌شود. اعلان فقط راه دسترسی است؛ **نصب نیاز به اقدام و تأیید کاربر دارد**. شبکهٔ unmetered معمولاً Wi-Fi است، نه تضمین رایگان‌بودن اینترنت از طرف اپراتور.

بررسی دانلود پس‌زمینه دیگر قفل مشترک با درخواست metadata رابط کاربری ندارد؛ انتظار دانلود قابل interrupt است. راه‌اندازی موفق worker نیز شکست راه‌اندازی صفحهٔ اصلی محسوب نمی‌شود.

## محدودیت‌ها و ارتقا

تست گوشی واقعی، شبکهٔ خصوصی، نشت، DNS/IPv6، Doze، handover و باتری همچنان NOT_RUN است. CI جای این آزمایش‌ها را نمی‌گیرد. سرعت و قطع‌نشدن مطلق تضمین نمی‌شوند؛ کانفیگ چندمسیرهٔ مبهم بدون مدرک سبز یا برنده اعلام نمی‌شود. DNS مستقل، انتقال TTL cache و تمام بهینه‌سازی‌های native تکمیل نشده‌اند.

پیش از ارتقا پشتیبان رمزگذاری‌شده بگیرید؛ برنامه را حذف و داده‌ها را پاک نکنید. همین امضای دائمی برای ارتقا حفظ می‌شود.
