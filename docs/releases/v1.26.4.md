# Parvaz 1.26.4 — اتصال همگام، وضعیت دقیق‌تر و دانلود ادامه‌پذیر

نسخهٔ **1.26.4**، کد **31**، بستهٔ `com.parvaz.tunnel`؛ همان امضای دائمی نسل سوم. این نسخه تکمیل همهٔ کارهای audit یا تضمین حذف تأخیر شبکه نیست.

## تغییرات

- **جلوگیری از شروع دوبارهٔ ناخواسته:** callback شبکهٔ فرعی یا قدیمی نباید هسته را دوباره راه‌اندازی کند. عملیات START/RESTART/STOP/تعویض سرور همگام شده‌اند؛ یک worker و حداکثر یک جایگزین در صف وجود دارد. نتیجهٔ عملیات منسوخ اجازهٔ فعال‌کردن نشست جدید را ندارد.
- **وضعیت صادقانهٔ اتصال:** فعال‌شدن هستهٔ محلی، تأیید اینترنت نیست. صفحه، اعلان، ویجت و Tile بین «در حال بررسی»، «پاسخ دریافت شد» و «ارتباط تأییدنشده» تمایز می‌گذارند. پروب ناموفق به‌تنهایی تونل را قطع نمی‌کند. پاسخ endpoint از پراکسی محلی نیز مسیر سرور انتخابی یا کارکرد همهٔ برنامه‌ها را اثبات نمی‌کند.
- **گزارش زمان فقط با درخواست شما:** در منوی افزودن، «گزارش زمان اتصال» زمان ساخت VPN، مراحل داخل هسته، پاسخ HTTP و مشاهدهٔ بایت دریافتی را بدون URL/رمز/شناسهٔ پروفایل نشان می‌دهد. گزارشی خودکار باز یا ارسال نمی‌شود. زمان DNS و اولین پاسخ واقعی یک برنامه هنوز اندازه‌گیری نشده و صریحاً نامشخص است.
- **تحمل خطای گذرا:** برای هستهٔ زنده، حداقل سه نتیجهٔ بد متوالی لازم است؛ بایت دریافتی strike را پاک می‌کند. هنگام دریافت ترافیک از پروب اضافی صرف‌نظر می‌شود؛ پروب هم‌پوشان و نتیجهٔ نشست قدیمی رد می‌شوند.
- **انتخاب سرور:** از موتور واقعی پروتکل، سابقهٔ پاسخ و فقط منبع فعال استفاده می‌شود. حداکثر سه آزمون هم‌زمان در مجموع مجاز است؛ شکست زودهنگام همهٔ گزینه‌ها بی‌دلیل تا پایان timeout معطل نمی‌ماند. منابع آرشیوشده حذف نمی‌شوند و نتیجهٔ قدیمی پس از تغییر منبع/پیکربندی پذیرفته نمی‌شود.
- **ادامهٔ دانلود APK:** فایل ناقصِ مربوط به همان URL/نسخه/اندازه/هش نگه داشته می‌شود. Range معتبر ادامه می‌یابد؛ اگر سرور پشتیبانی نکند، فایل از صفر جایگزین می‌شود. هش کامل، بسته، نسخه و امضا پیش از نصب دوباره بررسی می‌شوند؛ فایل ناقص به نصب‌کننده داده نمی‌شود. **این قابلیت پس از نصب 1.26.4 برای دانلود به‌روزرسانی‌های بعدی فعال است؛ دانلود خود 1.26.4 با کد نسخهٔ نصب‌شدهٔ قبلی انجام می‌شود.**

## نصب و فایل‌ها

انتشار موفق این نسخه روی stable/latest خواهد بود و برای دکمهٔ به‌روزرسانی داخل برنامه نام‌گذاری شده است، نه prerelease:

- `Parvaz-1.26.4-arm64.apk`: دستگاه و سیستم‌عامل ARM64.
- `Parvaz-1.26.4.apk`: عمومی ARM32 + ARM64.
- `Parvaz-1.26.4-source.tar.gz`: سورس متناظر GPL، وابستگی‌های vendor و دستور ساخت.
- `SHA256SUMS.txt`: هش APKها و سورس.

**پیش از ارتقا بکاپ رمزدار بگیرید؛ برنامه یا داده‌هایش را حذف نکنید.** نصب روی نسخه‌های دارای امضای نسل سوم نیازمند تعویض کلید نیست؛ تأیید نصب Android لازم است. امضاهای قدیمی متفاوت سازگار نیستند.

## مرز شواهد و کارهای باز

پیش از انتشار، **277 آزمون بدون شکست/خطا/skip**، کامپایل، R8، lint، امضا/بسته/نسخه/هش و بسته‌بندی native روی کد اجرایی `5d05c9c` موفق شدند. شمار و شناسهٔ اجرای نهایی در [شواهد audit](https://github.com/hojjatrad/parvaz/blob/main/docs/audit/reliability-final-gates.json) ثبت می‌شود. پروب مستقل Android 10/14، آرشیو و بازیابی را با APK fixture منتشرشده و backend آزمایشی می‌سنجد، نه نصب و اتصال کامل این نسخه روی گوشی واقعی.

**گوشی واقعی، نصب درجا، پنل خصوصی، Kill Switch، نشت DNS/IPv6، Doze، باتری و handover هنوز تأیید عملی نشده‌اند.** کاربر فعلاً امکان اجرای این آزمون‌ها ندارد؛ این وضعیت PASS نیست. دستور آزمون در [چک‌لیست](https://github.com/hojjatrad/parvaz/blob/main/docs/audit/RELIABILITY-HARDWARE-fa.md) آمده است.

اندازه‌گیری مستقل DNS، انتقال TTL cache بین نمونه‌های native و بهینه‌سازی تکمیلی pooling/خروج قطعی فرایندها هنوز بازند. انتظار 300ms reconnect و debounce واقعی 1200ms حفظ شده‌اند؛ MUX عمومی، کاهش اعتبارسنجی TLS یا fallback مستقیم جدید برای سریع‌تر نشان‌دادن اتصال اضافه نشده است. DNS cache داخل پیکربندی معمول روشن می‌ماند؛ این به معنی اثبات cache migration یا نشت‌نداشتن نیست. اصلاح تأییدشدهٔ افزایش اتصال‌ها و بازیابی بکاپ حفظ شده‌اند.
