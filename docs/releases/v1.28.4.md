# پرواز ۱.۲۸.۴ — نمایش تأخیر اتصال فعال

- پاسخ HTTPS اولیه پیش‌تر فقط وضعیت تأیید اتصال را تغییر می‌داد و به ردیف فهرست نمی‌رسید. اکنون تیک موجود آمار همان پاسخ معتبر را برای ردیف تست‌نشدهٔ اتصال فعال نمایش و ذخیره می‌کند؛ بدون درخواست شبکه، هسته یا تایمر اضافی.
- نتیجه فقط متعلق به همان نشست، منبع، پروفایل و شبکه و در مدت اعتبار مدرک پذیرفته می‌شود. تست دستی و وضعیت/نتیجهٔ آن بازنویسی نمی‌شوند؛ پاسخ ناموفق و شمارندهٔ ترافیک عدد پینگ نمی‌سازند.
- هنگام تازه‌شدن اشتراک، به‌روزرسانی ردیف اکنون به شیء فعلی کانکشن متصل می‌شود؛ صرفاً ردیف قدیمی را دوباره رسم نمی‌کند. ردیف حذف/بایگانی‌شده بازگردانده نمی‌شود.

تأخیر مربوط به HTTPS از مسیر پروکسی است، نه ICMP یا سرعت دانلود. این نمایش خودکار فقط برای اتصال فعالِ تأییدشده است؛ برای سایر کانکشن‌ها تست تکی/گروهی وجود دارد. کانفیگ کاملِ مبهم بدون مدرک، عدد نمی‌گیرد. آزمون واقعی گوشی، نصب، همزیستی probe و VPN زنده، نشت/Doze/باتری انجام نشده‌اند. تغییرات DNS آزمایشگاهی وارد نسخه نشده‌اند.

نامزد انتشار؛ APK فقط پس از موفقیت گیت‌ها و امضای دائمی منتشر می‌شود. برنامه و داده‌ها حذف نشوند؛ پیش از ارتقا پشتیبان رمزدار بگیرید.
