# پرواز ۱٫۲۸٫۶ — فقط برای آزمایش نصب

**این نسخه نهایی نیست. بررسی امنیتی و آزمون ارتقای واقعی هنوز تکمیل نشده‌اند.**
این فایل بنا به درخواست صریح مالک برای آزمایش روی گوشی تهیه می‌شود؛ موفقیت ساخت یا امضا به معنی تأیید امنیت نیست. هشدارهای حل‌نشده در `vulnerability-review.json` همراه فایل‌ها قرار دارند و حذف یا بی‌اثر اعلام نشده‌اند.

- اصلاحات ممیزی در این کد وجود دارند. نام برنامه پس از نصب «پرواز (آزمایشی)» است.
- امضا همان کلید دائمی نسل۳ است؛ نسخهٔ قبلی را حذف نکنید. **پیش از نصب، از داخل برنامه پشتیبان رمزدار بگیرید.** حفظ داده‌ها در ارتقای واقعی هنوز آزموده نشده است.
- فایل `TEST-arm64.apk` برای گوشی‌های ARM64؛ فایل `TEST.apk` برای ARM32 و ARM64 است.
- این انتشار **Prerelease** است و Latest نیست؛ دکمهٔ بروزرسانی عمومی آن را دریافت نمی‌کند. برای آزمایش، APK را مستقیم دانلود و نصب کنید.
- کد نسخه۴۰ است؛ نسخهٔ نهایی بعدی باید حداقل کد۴۱ و نام نسخهٔ بزرگ‌تر از۱٫۲۸٫۶ داشته باشد تا از این آزمایشی هم قابل ارتقا باشد.
- بازگشت مستقیم به۱٫۲۸٫۵ معمولاً به‌دلیل کاهش کد نسخه توسط اندروید مسدود می‌شود. برای برگشت، داده‌ها را بی‌پشتیبان پاک نکنید.
- لطفاً نتیجهٔ نصب/بازشدن، باقی‌ماندن سرورها، اتصال و پینگ، انتخاب پیش‌فرض و قفل برنامه را بررسی کنید؛ عکس یا شرح خطا کافی است. لینک خصوصی، UUID، رمز یا فایل پشتیبان را عمومی ارسال نکنید.

منبع متناظر GPL و هش فایل‌ها همراه این انتشار هستند. هیچ تضمین تازه‌ای دربارهٔ همهٔ شبکه‌ها، DNS/IPv6 یا محدودیت‌های سازندگان داده نمی‌شود.
