# Parvaz 1.28.2 — پیوستگی تشخیص DNS پس از قطع و برگشت شبکه

versionCode 36؛ همان بسته و گواهی دائمی. این نسخه انتشار جدید است؛ نسخه‌های قبلی بازنویسی نمی‌شوند.

## تغییرات

- بازگشت همان Network handle بعد از فقدان شبکه، دیگر نشانهٔ ثابت‌ماندن DNS فرض نمی‌شود. مشخصات جاری دوباره خوانده می‌شوند؛ DNS متفاوت، cache قبلی را نامعتبر می‌کند. اگر snapshot شناخته‌شدهٔ DNS ثابت باشد، صرف برگشت شبکه موجب بازسازی cache نمی‌شود؛ تأیید HTTPS دوباره لازم است.
- اگر مشخصات DNS هنگام تغییر/برگشت شبکه در دسترس نباشند، رسیدن دیرتر آن‌ها «اولین baseline بی‌اثر» حساب نمی‌شود. نسل resolver دوباره تغییر می‌کند تا هسته‌ای که در فاصلهٔ نامشخص ساخته شده، نتواند برای سیاست جدید تأیید صادر کند. این محافظ ممکن است یک بازسازی اضافی ایجاد کند؛ ادعای قطع‌نشدن نیست.
- هویت resolver به‌صورت snapshot جداشده و ساختاریافته نگه داشته می‌شود. نبود دامنه با رشتهٔ واقعی `null` یکی نیست؛ ترتیب DNSها و scope IPv6 حفظ می‌شوند. نام نمایشی InetAddress هویت IP را عوض نمی‌کند. مشخصات فقط در حافظه‌اند و نمایش متنی این شیء redacted است.
- شروط HTTPS، سن مدرک شامل خواب، منبع فعال، حذف مکث 300ms و نگهداری ظرفیت native تا خروج واقعی حفظ شده‌اند. نوسان گذرای اعتبارسنجی Private DNS به‌تنهایی هویت resolver را عوض نمی‌کند.

## مرز این مرحله

این نسخه flush درجا، انتقال TTL/cache بین موتورهای متفاوت یا زمان‌سنجی مستقل DNS را پیاده نمی‌کند. هیچ کنترلر عمومی یا endpoint جدیدی فعال نشده است. بازسازی امن هسته برای تغییر سیاست شناخته‌شده حفظ می‌شود و ممکن است سوکت‌های باز را قطع کند.

در Xray پین‌شده، رابط `features/dns.Client` بررسی‌شده LookupIP دارد؛ CacheCleanup رکوردهای منقضی را پاک می‌کند و migration داخلی در همان کنترلر، قرارداد انتقال cache بین هسته‌ها نیست. patch معتبر برای همهٔ لایه‌ها و جلوگیری از بازگشت پاسخ درحال‌پرواز هنوز لازم است. جزئیات در `docs/audit/DNS-CACHE-BOUNDARY-fa.md` است.

آزمون‌های callback و snapshot شبیه‌سازی نرم‌افزاری‌اند؛ تست گوشی، پنل خصوصی، نشت DNS/IPv6، باتری، Doze، handover و نصب کاربر NOT_RUN است. تغییر معنای DNS بدون تغییر قابل مشاهدهٔ سیستم لزوماً قابل تشخیص نیست. اولین پاسخ مستقل برنامه نیز اندازه‌گیری نشده است.

پیش از ارتقا پشتیبان رمزدار بگیرید؛ برنامه و داده‌ها را حذف نکنید.
