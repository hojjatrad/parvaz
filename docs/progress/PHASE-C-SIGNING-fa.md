- اجرای انتشار `34311459935` قبل از ساخت/تأیید APK شکست خورد. هیچ APK یا Release جدیدی منتشر نشده است.

- رمزها/فایل خصوصی در گزارش‌ها چاپ یا به artifact عمومی صادر نشده‌اند. workflow بازیابی مجوز `contents: read` دارد و چیزی منتشر نمی‌کند.

## سوابق انجام‌شده

- دسترسی SSH با Deploy Key آزمایش شد و ارسال کد موفق بود.
- اصلاحات تا پایان مرحلهٔ B به شاخهٔ `fix/panel-import-and-stable-refresh` در GitHub ارسال شدند؛ شاخهٔ `main` و APK منتشرشدهٔ قبلی تغییر نکردند.
- مجموعهٔ رگرسیون در GitHub Actions واقعاً اجرا و موفق شد:
  https://github.com/hojjatrad/parvaz/actions/runs/34273416509
- یک کلید دائمی جدید RSA-4096 در قالب PKCS12 ساخته شد. وجود private-key entry و تطبیق گواهی عمومی با اثرانگشت ثبت‌شده بررسی شد.
- گواهی عمومی و fingerprint در `docs/signing/` هستند؛ کلید خصوصی و رمزها وارد Git نمی‌شوند.
- پشتیبان حساس مالک پروژه جدا از مخزن آماده شده است. محیط گفتگو را محل نگهداری دائمی کلید فرض نکنید.
- شمارهٔ نسخهٔ سورس برای نسل جدید به ۱.۱۹ / versionCode 19 تغییر کرد؛ این به معنی ساخته‌شدن یا انتشار APK نیست.
- workflow ساخت Android بدون کلید انتشار و workflow جداگانهٔ امضا/انتشار Pre-release آماده شدند؛ راهنمای تنظیم در `docs/signing/SETUP-fa.md` است.

## شرط امضای همهٔ نسخه‌های بعدی

اثر انگشت مورد انتظار گواهی:

```text
8c6b2c7979c254cb3c77a3fe005082abbe414cb98e48835dbc428c890ecf30f7
```

workflow انتشار ابتدا گواهی داخل keystore و پس از ساخت، امضای خود APK را با این fingerprint مقایسه می‌کند.
همچنین شناسهٔ برنامه، versionCode/versionName و checksum فایل‌ها بررسی می‌شوند.
در صورت نبودن Secret، کلید اشتباه، شکست تست/ساخت یا وجود انتشار قبلی با همان شماره، انتشار باید متوقف شود.
ساخت کلید تازه یا fallback به کلید debug راه‌حل خطا نیست.

## کاری که فقط مالک مخزن باید یک‌بار انجام دهد

۱. بستهٔ پشتیبان کلید را دریافت و در محل امن نگهداری کند؛ بسته شامل کلید و رمز است و نباید عمومی شود.
۲. چهار فایل متنی داخل آن را در GitHub Actions **Secrets** با نام‌های زیر ثبت کند:

- `PARVAZ_KEYSTORE_BASE64`
- `PARVAZ_KEYSTORE_PASSWORD`
- `PARVAZ_KEY_ALIAS`
- `PARVAZ_KEY_PASSWORD`

Deploy Key مجوز نوشتن این Secrets از طریق API را ندارد؛ توکن شخصیِ قبلاً ارسال‌شده در چت استفاده نشده است.
تا تکمیل این مرحله، امضای release در GitHub آمادهٔ اجرا نیست.

## هشدار نصب

به‌دلیل تغییر امضا، اولین APK این نسل روی نسخهٔ قدیمی به‌صورت آپدیت نصب نمی‌شود.
باید پیش از حذف نسخهٔ قبلی، از کانفیگ‌ها و تنظیمات پشتیبان گرفته شود و رمز پشتیبان محفوظ بماند.
نسخه‌های بعدی که با همین کلید و شمارهٔ نسخهٔ بالاتر ساخته شوند، می‌توانند روی نسل جدید به‌روزرسانی شوند.
هیچ اقدام حذف/نصب روی گوشی کاربر انجام نشده است.

## هنوز انجام‌نشده

ساخت debug و تست‌ها موفق بوده‌اند؛ ساخت release امضاشده، تأیید خود APK، انتشار فایل نصب و آزمون نصب/بازیابی/اتصال
روی گوشی هنوز انجام نشده‌اند. workflow جدید صرفاً با آماده‌شدن فایلش «تأییدشده» محسوب نمی‌شود.
انتشار اولیه باید تا پایان آزمون دستگاه Pre-release بماند؛ خطاهای مستقل هات‌اسپات، تست نشت و هستهٔ
Hysteria2/TUIC نیز با ساخت کلید جدید حل نشده‌اند.
