# تحویل نسخهٔ 1.21 پرواز

**منتشر شده و روی مسیر رسمی latest قرار دارد.** امضای دائمی نسخه‌های 1.19.1 و 1.20 تغییر نکرده است. versionCode برابر 22 است.

- [صفحهٔ انتشار](https://github.com/hojjatrad/parvaz/releases/tag/v1.21)
- [APK برای ARM64](https://github.com/hojjatrad/parvaz/releases/download/v1.21/Parvaz-1.21-arm64.apk)
- [APK جامع](https://github.com/hojjatrad/parvaz/releases/download/v1.21/Parvaz-1.21.apk)

## تغییرات قابل استفاده

1. پاسخ‌های JSON رشته‌ای و Base64 داخل JSON، فیلد links رشته‌ای و پوشش متداول لینک بهتر تشخیص داده می‌شوند.
2. پاسخ خالی/نامعتبر با حداکثر سه قالب متداول روی همان URL بررسی می‌شود؛ اعتبارسنجی TLS و ورود کنار گذاشته نمی‌شود.
3. نتیجهٔ صفر، گزارش واضح دارد. «گزارش آخرین افزودن» از منوی افزودن قابل مشاهده و کپی است؛ URL خصوصی، توکن و بدنهٔ پاسخ در آن نیست.
4. ورود موفق، صفحهٔ سرورها را باز می‌کند.
5. بستهٔ AndroidLibXrayLite به **v26.9.9** ارتقا یافته؛ فایل رسمی با SHA-256 بررسی شده است.
6. بررسی خودکار آپدیت در برنامه، تلاش مجدد در خطا و صفحهٔ رسمی دانلود اضافه شده‌اند.
7. نگهداری روزانهٔ هسته روی main تنظیم شده است. ساخت، تست، امضای ثابت و بررسی APK شرط انتشار هستند. انتشارهای آینده قفل مشترک و محافظ جلوگیری از عقب‌رفتن نسخهٔ برنامه، versionCode و هسته دارند.

## شواهد

- **245 assertion میزبان** موفق؛ آزمون TLS این مجموعه روی JVM میزبان است، نه trust-store گوشی.
- **تست‌های Robolectric برای SDK 29 و 34** موفق، شامل مسیر حافظهٔ موقت → HTTP سرور آزمایشی → تشخیص → فهرست واقعی رابط، و نمایش گزارش برای پاسخ صفر.
- [اعتبارسنجی ساخت و امضا](https://github.com/hojjatrad/parvaz/actions/runs/34322784900): موفق.
- [تست، ساخت، امضا و انتشار منبع دقیق تگ](https://github.com/hojjatrad/parvaz/actions/runs/34323262120): موفق.
- [بررسی همان API مورد استفادهٔ دکمهٔ آپدیت](https://github.com/hojjatrad/parvaz/actions/runs/34323716256): موفق؛ v1.21 عادی و latest است و URL/اندازه/SHA فایل‌ها درست است. محافظ ترتیب نسخه نیز با یک نامزد مصنوعی، بدون انتشار، بررسی شد.
- SHA هر دو APK از طریق خواندن مستقیم فایل منتشرشده مستقل محاسبه و با checksum تطبیق داده شد؛ APKها در فضای محلی نگه داشته نشدند.
- 17 تست Python در منبع تگ، و 23 تست پس از افزودن محافظ‌های انتشار آینده موفق‌اند.
- بررسی upstream نسخهٔ v26.9.9 را تأیید کرد. انتشار خودکارِ ناشی از یک نسخهٔ آیندهٔ upstream هنوز رخ نداده است.

## آزمونی که هنوز لازم است

ساب خصوصی کاربر و اتصال واقعی روی گوشی آزمایش نشده‌اند. بنابراین رفع قطعی همان مورد یا کارکرد همهٔ پنل‌ها ادعا نمی‌شود.

پس از نصب 1.21 از دکمهٔ آپدیت، ساب را دوباره اضافه کنید. اگر فهرست همچنان خالی بود:

**افزودن → گزارش آخرین افزودن → کپی گزارش امن**

فقط متن گزارش را ارسال کنید؛ لینک دارای توکن لازم نیست. برنامه را برای نصب روی 1.19.1 یا 1.20 حذف نکنید.

هسته داخل APK است و با نصب آپدیت برنامه عوض می‌شود. نصب به تأیید Android نیاز دارد. شبکه، زمان‌بندی GitHub، مجوزهای مخزن یا شکست تست‌ها می‌توانند انتشار را به تأخیر بیندازند. هر دریافت HTTP همچنان سقف 60 ثانیه دارد و بررسی سه قالب ممکن است طولانی‌تر شود.

فایل موقت دانلود هسته و نسخهٔ بررسی‌شدهٔ آن حذف شدند؛ حدود **19.74 GiB فضای آزاد** باقی است. فایل‌های خصوصی امضا و نسخهٔ پشتیبان دست‌نخورده‌اند.
