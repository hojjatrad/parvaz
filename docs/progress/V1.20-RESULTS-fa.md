# نتیجهٔ اصلاحات نسخهٔ 1.20 — ۹ سپتامبر ۲۰۲۶

## تحویل

نسخهٔ **1.20 / versionCode 21** به‌صورت انتشار عادی و Latest روی GitHub قرار گرفت:
https://github.com/hojjatrad/parvaz/releases/tag/v1.20

گواهی همان گواهی دائمی نسل ۳ نسخهٔ 1.19.1 است و کلید عوض نشده است. آپدیت از 1.19.1 نیازی به حذف برنامه ندارد؛ نصب از نسل قدیمیِ امضای 1.18 همچنان مهاجرت و پشتیبان می‌خواهد. نصب نهایی با اجازهٔ کاربر و تأیید Android انجام می‌شود.

## ریشهٔ خطاها و اصلاحات

| مورد | یافته و راه‌حل |
|---|---|
| ساب در حافظهٔ موقت قبول نمی‌شد | مسیر قبلی فقط LinkParser را روی URL اجرا می‌کرد. اکنون حافظهٔ موقت، لینک دستی و QR به یک واردکنندهٔ غیرهمزمان می‌روند؛ HTTP(S) به‌عنوان ساب دریافت می‌شود و محتوای پاسخ تشخیص داده می‌شود. |
| دو نسخه از اتصال | ثبت هر بار ساب UUID تازه می‌ساخت؛ QR نیز دو بار import داشت. URL یکسان دوباره ثبت نمی‌شود؛ QR یک اجرا دارد؛ پاک‌سازی ساب‌های تکراری و رکوردهای هم‌منبع اضافه شد. |
| اتصال یکسان در منابع مستقل | در فهرست فقط یک ردیف نمایش داده می‌شود؛ رکوردهای مالکیت مستقل زیر آن نگهداری می‌شوند تا آپدیت یک ساب، سرور ساب دیگر را از بین نبرد. انتخاب و علاقه‌مندی به ردیف نماینده منتقل می‌شوند. |
| همهٔ سرورهای پاسخ دیده نمی‌شدند | چند outbound معتبر Xray و envelopeهای صریح data/configs خوانده می‌شوند. پاسخ ناقص سرورهای معتبر را اضافه می‌کند، اما لیست قبلی را حذف نمی‌کند. خطا/گزینهٔ پشتیبانی‌نشده گزارش می‌شود. |
| درصد ثابت حجم | fallback به پلن دستی، آمار ذخیره‌شدهٔ دستگاه و ساب نامرتبط حذف شد. فقط metadata منبع همان اتصال نمایش داده می‌شود؛ کپی دستی همان اتصال تنها وقتی یک منبع ساب مشخص دارد می‌تواند از آن metadata بگیرد. |
| نبودن اطلاعات حجم | URL خالی/نامعتبر، منبع نامرتبط یا metadata غایب، صفر همراه توضیح «اطلاعات دریافت نشده» می‌دهد. صفر در این حالت ادعای صفر بودن مصرف واقعی حساب نیست. |
| خودکاربودن حجم | هنگام باز بودن برنامه هر ۵ دقیقه refresh انجام می‌شود و زمان دریافت کنار عنوان می‌آید؛ پس‌زمینه به‌طور پیش‌فرض ساعتی و تابع محدودیت‌های WorkManager/شبکه است. تنظیم صریح غیرفعال قبلی حفظ می‌شود. |
| دکمهٔ آپدیت | کلاینت نصب‌شده /releases/latest را می‌خواند و Pre-release را نمی‌بیند. 1.20 در کانال عادی قرار گرفت و همان endpoint واقعاً بررسی شد. نسخهٔ جدید برای آپدیت‌های بعدی اندازه/هش و بسته/نسخه/امضا را نیز بررسی می‌کند. |

## آزمون‌های موفق

- ۲۲۹ assertion میزبان: parser، TLS/HTTP loopback، ذخیره/refresh و ۳۸ مورد ورود هوشمند/تکرار/حجم.
- ۷ متد تست جدید Robolectric روی API 29 و 34، در کنار تست‌های قبلی Android. یک تست خودِ MainActivity را می‌سازد: 43% قدیمی را در نبود ساب صفر می‌کند؛ با metadata معتبر 43% نشان می‌دهد؛ پس از حذف URL دوباره صفر می‌کند؛ فهرست و علاقه‌مندی اتصال تکراری را نیز بررسی می‌کند.
- اجرای ساخت و امضای قبل از انتشار: https://github.com/hojjatrad/parvaz/actions/runs/34318591297 — موفق.
- اجرای انتشار: https://github.com/hojjatrad/parvaz/actions/runs/34318975182 — موفق.
- بررسی API دکمهٔ آپدیت، نام/اندازه/هش هر دو APK و non-prerelease بودن: https://github.com/hojjatrad/parvaz/actions/runs/34319345350 — موفق.
- هر دو دانلود عمومی مجدداً خوانده شدند و SHA-256 آن‌ها با فایل checksum و هش نمایش‌داده‌شدهٔ GitHub یکسان بود. APKها محلی ذخیره نشدند.
- جزئیات ماشین‌خوان و هش‌ها: `docs/releases/v1.20-verification.json`.

## استفاده

۱. در نسخهٔ 1.19.1 دکمهٔ «به‌روزرسانی نرم‌افزار» را بزنید و نصب Android را تأیید کنید؛ برنامه را حذف نکنید.
۲. پس از آپدیت، از منوی افزودن گزینهٔ «پاک‌سازی کانکشن‌های تکراری» را اجرا کنید.
۳. لینک ساب یا کانفیگ را کپی کنید و «افزودن از حافظهٔ موقت» را بزنید؛ دریافت شبکه در پس‌زمینه انجام می‌شود.
۴. اگر ساب اطلاعات حجم ارسال نکند، برنامه نمی‌تواند حجم واقعی را حدس بزند. در قطع اینترنت، آخرین مقدار دریافت‌شده با زمانش باقی می‌ماند، نه یک مقدار ساختگی زنده.

## محدودیت و آزمون بعدی

نصب/ارتقای واقعی روی گوشی و اتصال به پنل‌های خصوصی کاربر هنوز توسط دستیار آزمایش نشده است. پذیرش فایل به معنی پشتیبانی همهٔ گزینه‌ها یا اجرای کامل routing/groups/providers نیست. Hysteria2/TUIC با هستهٔ فعلی قابل اتصال نیستند.
لینک کامل اشتراک، رمز، UUID و پشتیبان امضای برنامه نباید در گزارش عمومی یا چت قرار بگیرند.
