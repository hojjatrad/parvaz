# نمایش تأخیر پاسخ اولیه — ۱٫۲۸٫۴

## نقص و اصلاح

تأیید اولیهٔ HTTPS فقط در StartupDiagnostics ثبت می‌شد. تیک آمار وضعیت تأیید را نمایش می‌داد، اما عدد را نمی‌فرستاد؛ عدد ردیف به تست دستی یا اندازه‌گیری بعدی سلامت وابسته بود. اکنون مدتِ آخرین پاسخ موفق، جدا از مدتِ آخرین تلاش ناموفق نگه داشته می‌شود. تیک موجود آمار از همان مدرک، ردیف تست‌نشدهٔ اتصال فعال را پر و در pings ذخیره می‌کند و همان broadcast آمار شامل ping است. تایمر، درخواست HTTPS و کنترلر جدید اضافه نشده است.

مسیر callback همچنان فقط به diagnostics می‌رود؛ callback در حال نگه‌داشتن قفل ReadinessMonitor وارد CoreManager نمی‌شود. انتقال به store از ticker با مالکیت عملیات و نشست صورت می‌گیرد. source revision، شیء اصلی، fingerprint، subscription و اعتبار شبکه/resolver تا لحظهٔ نوشتن بررسی می‌شوند. پاسخ منسوخ، صرف RX، هستهٔ صرفاً روشن، شکست و مسیر نامعلوم عدد تولید نمی‌کنند. وضعیت یا نتیجهٔ تست دستی بازنویسی نمی‌شود؛ یک پاسخ اولیه تکراراً در هر تیک ذخیره نمی‌شود.

در UI، notify قبلی فقط شیء موجود در لیست adapter را دوباره رسم می‌کرد. اکنون canonical row از منبع فعال خوانده می‌شود؛ ردیف حذف/بایگانی‌شده از نمای مربوط کنار می‌رود. این تغییر منابع بایگانی را حذف یا دوباره فعال نمی‌کند.

## آزمون

15 روش جدید روی SDK29 و SDK34 اجرا شدند (30 اجرا): اتصال محلی/RX، پاسخ ناموفق و مسیر نامعلوم، مدت شکست پس از موفقیت، تغییر شبکه/resolver، انقضا، نشست قدیمی/متوقف، ویرایش اعتبارنامه، جایگزینی منبع، عدم بازنویسی تست دستی، بررسی دوبارهٔ proof در write، جایگزینی ردیف و متن واقعی TextView، حذف نمای ردیف ناموجود، و انتقال ticker → broadcast → receiver → نمایش ردیف. این‌ها با مدرک تزریق‌شده و اجزای تولیدی انجام شدند؛ تست VPN واقعی گوشی نیستند.

- commit اجرایی: `478529802b6b9b02897af0d4eebca20781a4cadf`؛ نسخهٔ 1.28.4 / code 38.
- 14 gate موفق، 444 تست واحد بدون failure/error/skip، 36 تست Python انتشار و audit میزبان موفق.
- 15 آزمون native و 11 آزمون آرشیو/پشتیبان روی هر SDK29/34 شبیه‌ساز موفق.
- APKهای عمومی کامل دریافت و امضا با apksig رسمی، pin نسل سوم، package/version، ABI و ELF هر سه هسته بررسی شدند. سورس کامل streaming هش شد و SHA256SUMS و digestهای GitHub برابرند.
- stable latest و مسیر کشف آپدیت بررسی شدند؛ نام، حجم و digest فایل‌های هفت انتشار قبلی و release IDها محفوظ‌اند. APKهای دانلودی پس از بررسی حذف شدند.

## محدودیت

نسخهٔ نصب‌شده و اقدام دقیق کاربر مشخص نشد؛ بازتولید گزارش روی گوشی NOT_RUN است. اصلاح خودکار فقط ردیف تست‌نشدهٔ اتصال فعالِ دارای مدرک را پر می‌کند. برای سایر کانکشن‌ها تست تکی/گروهی لازم است. این عدد تأخیر HTTPS است، نه ICMP، سرعت دانلود یا تضمین کیفیت ثابت. کانفیگ کاملِ مبهم بدون مدرک عدد نمی‌گیرد. نصب، همزیستی probeهای Xray با VPN زنده، نشت، Doze و باتری روی سخت‌افزار انجام نشده‌اند. DNS آزمایشگاهی وارد APK نشده است؛ پاک‌سازی درجا و انتقال TTL کامل نیست. برنامه/داده‌ها حذف نشوند و پیش از ارتقا پشتیبان رمزدار گرفته شود.
