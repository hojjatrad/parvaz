# پیگیری اصلاحیهٔ 1.26.1 — انتشار پایدار تأیید شد

> گزارش تاریخیِ 1.26.1: اصلاح محدودِ اعتبارسنجی پورت بکاپ در **1.26.2** منتشر شد؛ [شواهد نسخهٔ جدید](STATUS-v1.26.2-fa.md).
نسخهٔ **1.26.1 / code 28** با شناسهٔ بسته و گواهی دائمی نسل سوم منتشر شد. این کار ادامهٔ آزمون موارد باقی‌مانده است، نه بازطراحی ساب.

## انتشار و آپدیت

- [34367420763](https://github.com/hojjatrad/parvaz/actions/runs/34367420763): انتشار نهایی روی تگ `v1.26.1` با کد `5b6d0c4` موفق؛ تفاوت آن با کد اجرایی آزموده‌شدهٔ `31c262b` فقط مستندات بود. ساخت، lint، واحدها، امضا، نسخه/بسته/هش، سقف حجم و کنترل بسته‌بندی native و ترتیب انتشار گذشتند.
- API عمومیِ بدون توکن `/releases/latest` نسخهٔ **v1.26.1** را به‌صورت stable و نه draft/prerelease برگرداند؛ نام، URL، اندازه و digest هر دو APK با شروط updater نصب‌شده منطبق است.
- هر چهار فایل عمومی مستقلاً خوانده شدند؛ SHA-256 کامل APKها و سورس با SHA256SUMS و digest گیت‌هاب برابر بود. هیچ APK یا آرشیو سورس حجیمی در فضای کار نگه داشته نشد.
- ARM64: **45,367,828 بایت**؛ عمومی ARM32+ARM64: **88,646,570 بایت**؛ سورس متناظر: **477,404,220 بایت**. هر دو APK زیر سقف 128 MiB هستند.
- کنترل انتشار بعدی با سورس عمومی انجام شد: نامزد مصنوعی 1.26.2/code29 پذیرفته شد؛ تکرار 1.26.1/code28 رد شد. هیچ انتشار اضافی انجام نشد.
- [فایل‌های انتشار](https://github.com/hojjatrad/parvaz/releases/tag/v1.26.1) · [رکورد هش‌ها و شواهد](../releases/v1.26.1-verification.json). تگ و فایل‌های 1.26 و نسخه‌های قدیمی دست‌نخورده‌اند؛ این گزارش پس از انتشار در main تکمیل شده است.

## ایراد بازتولیدشده

[34364922319](https://github.com/hojjatrad/parvaz/actions/runs/34364922319) روی `2686614` با کد اجرایی 1.26: آزمون پایان رشتهٔ موقت برای **هر دو sing-box و Mihomo روی API 29 شکست خورد** (`Engine died when its calling thread exited`). آزمون قبلی رشتهٔ درخواست‌دهنده را زنده نگه می‌داشت و این حالت را پوشش نمی‌داد.

محافظ Linux با `PR_SET_PDEATHSIG` به عمر رشتهٔ forkکننده وابسته است. مسیر راه‌اندازی VPN در برنامه از یک رشتهٔ موقت استفاده می‌کند؛ در نتیجه زنده‌ماندن فرایند اصلی به‌تنهایی برای نگه‌داشتن هسته کافی نبود. fixture کوچک مستقل روی Linux نیز خروج فرزند با SIGKILL پس از پایان رشتهٔ والد را بازتولید کرد؛ شاهد Android، اجرای بالا است.

## اصلاح

در `31c262b`، ساخت فرایند به یک executor خصوصیِ تک‌رشته‌ای و پایدار منتقل شد. رشتهٔ راه‌انداز تا پایان فرایند برنامه باقی می‌ماند؛ محافظ native حذف نشده است. `launch` و `close` همگام شده‌اند تا بسته‌شدن نشست با ساختِ در صف/در حال انجام تداخل نکند. فهرست ساب، منابع بایگانی‌شده، TLS تولیدی و کلید امضا تغییر نکرده‌اند.

## نتیجهٔ آزمون‌ها

- [34365898301](https://github.com/hojjatrad/parvaz/actions/runs/34365898301) روی `31c262b`: **موفق**. کلاس آزمون روی هر دو شبیه‌ساز x86_64 با API 29 و 34 اجرا شد:
  - پایان رشتهٔ موقت، هیچ‌کدام از دو هسته را نمی‌کشد؛ پس از پایان آن رشته، TCP واقعی ردوبدل می‌شود.
  - مرگ عمدی فرایند صاحب هسته، از طریق قطع Binder دیده می‌شود و درگاه هر دو هسته بسته و قابل bind مجدد می‌شود؛ بستن عادی `ExternalCore.close()` در فرایندِ کشته‌شده اجرا نمی‌شود.
  - HY2/TUIC با TLS فعال، TCP/UDP و رد SNI نادرست آزموده شدند؛ پس از قطع سرور، درخواست TCP به مسیر مستقیم برنمی‌گردد.
  - راه‌اندازی و رد دسترسی بدون احراز هویت و آزمون‌های پروتکل روی میزبان نیز موفق‌اند.
- گواهی موقت فقط در network-security-config برنامهٔ کمکی debug مورد اعتماد قرار می‌گیرد. گواهی/Service/manifest آزمایشی در APK اصلی نیست و از `allowInsecure` برای این fixture جدید استفاده نشده است.
- [34365899048](https://github.com/hojjatrad/parvaz/actions/runs/34365899048): کامپایل Android، واحدها و R8 موفق.
- آزمون host محلی و 25 آزمون ابزار انتشار موفق؛ بخش refresh/dedup همچنان 53 assertion موفق دارد.
- [34365897839](https://github.com/hojjatrad/parvaz/actions/runs/34365897839): موفق: کلید دائمی، lintDebug/lintRelease، واحدها، ساخت APK امضاشده، package/version/hash، سقف 128 MiB و تطابق/alignment هسته‌های تازه گذشتند. سورس متناظر 477,407,650 بایت ساخته شد؛ این اندازه مربوط به اعتبارسنجی پیش از تگ است.

## آزمون تکمیلی پس از انتشار

[لغو و پاک‌سازی هسته‌ها](NATIVE-CANCELLATION-fa.md) با کد اجراییِ بدون تغییر انجام شد: 12 تست روی API 29 و 12 تست روی API 34، همگی بدون شکست/خطا/skip. سناریوهای تازه شامل لغو در صف، لغو انتظار ظرفیت، رد راه‌اندازی دیررسِ نشست بسته و چهار چرخهٔ توقف با بررسی خروج فرزند/پاک‌شدن CA/آزادشدن پورت هستند. APK تازه لازم نشد و نسخهٔ پایدار همان 1.26.1 باقی ماند.

## حدود ادعا

این پروب برنامهٔ کمکی است، نه اجرای کامل برنامهٔ VPN. بسته‌شدن listener پس از مرگ صاحب فرایند، اثبات نبود نشت DNS/IPv6 یا عملکرد کامل Kill Switch نیست. گوشی واقعی ARM، نصب درجا، پنل‌های خصوصی، جابه‌جایی Wi-Fi/mobile، Doze/باتری و کلاینت LAN هنوز آزموده نشده‌اند. پاسخ سؤال وضعیت نصب از کاربر دریافت نشده؛ آزمایش گوشی به‌اشتباه موفق ثبت نمی‌شود.

برای سایر اصلاحات و محدودیت‌های قالب‌های کامل، رمزگذاری/بکاپ و هات‌اسپات، [گزارش 1.26](STATUS-v1.26-fa.md) پابرجاست. تگ‌ها و فایل‌های قبلی تغییر نمی‌کنند؛ سورس متناظر باید کنار APK اصلاحیه منتشر شود.
