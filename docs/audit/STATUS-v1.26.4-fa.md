شبکهٔ پیش‌فرض، صف محدود اتصال، نتیجهٔ منسوخ، وضعیت صادقانه، گزارش دستی زمان، تحمل probe ناموفق، انتخاب موتور واقعی از منبع فعال و ادامهٔ دانلود بهبود یافته‌اند. ادامهٔ دانلود پس از نصب 1.26.4 برای آپدیت‌های بعدی فعال می‌شود؛ کد downloader نصب‌شدهٔ 1.26.3 با انتشار این نسخه از راه دور تغییر نمی‌کند.

DNS مستقل و اولین پاسخ واقعی یک برنامه هنوز اندازه‌گیری نمی‌شوند؛ RX شامل پروب/DNS هم هست و HTTP از loopback مسیر outbound انتخابی را اثبات نمی‌کند. انتقال TTL cache بین نمونه‌های native و pooling/خروج قطعی فرایندها بازند. انتظار 300ms و debounce واقعی 1200ms باقی مانده‌اند. STOP با کار native همگام می‌شود؛ تأخیر/ANR و آزادشدن واقعی منابع روی گوشی هنوز آزموده نشده‌اند.

کاربر گزینهٔ «فعلاً امکان تست ندارم» را انتخاب کرده است. **گوشی واقعی، نصب درجا، پنل خصوصی، Kill Switch، نشت DNS/IPv6، تغییر شبکه و Doze/باتری NOT_RUN هستند.** آزمون fixture، ساخت یا امضای موفق به معنی رفع قطعی تأخیر گوشی یا تأیید کامل این موارد نیست.
