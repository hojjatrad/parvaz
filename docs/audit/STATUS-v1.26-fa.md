# پیگیری اصلاحات 1.26 — هنوز منتشر نشده

این سند وضعیت شاخهٔ توسعه است، نه تأیید انتشار APK یا پایان همهٔ آزمون‌ها. آخرین نسخهٔ عمومی در زمان نگارش همچنان **1.25 / code 26** است. مشکل زیادشدن اتصال‌ها را کاربر در همان نسخه تأیید کرده که رفع شده؛ آن مسیر بازطراحی نشده است.

## خطاهایی که آزمون‌ها پیدا کردند

- تفاوت escape کاراکتر `/` در JSON اندروید و خوانندهٔ YAML میهومو اصلاح شد.
- Android 14: sing-box در outbound مستقیم، مانیتور رابطِ ناموجود را dereference می‌کرد. patch محدود و مشخص افزوده شد؛ اجرای `34356644136` راه‌اندازی، احراز هویت و تبادل TCP هر دو موتور را روی API 29 و 34 تأیید کرد. مجوز root یا دسترسی ویژه درخواست نمی‌شود.
- lint: شرط محافظ امضا بیش از حد گسترده بود و JAR کلاس‌های lint را هم بستهٔ انتشار حساب می‌کرد. شرط اصلاح شد؛ محافظ APK/AAB حفظ شده است. اجرای امضاشدهٔ `34357616744` شامل lint، واحدها، سورس متناظر و اعتبارسنجی APK موفق شد. baseline میراثی حذف نشده و هشدارهای ابزار ساخت باقی‌اند.
- سازگاری اعتماد TLS: مسیرهای قدیمی CA در Go به‌تنهایی پوشش Conscrypt APEX اندروید جدید را تضمین نمی‌کنند. هستهٔ فرزند اکنون گواهی‌های عمومی CA را از TrustManager پیش‌فرض Android در پوشهٔ خصوصی موقت می‌گیرد. کلید خصوصی صادر نمی‌شود و TLS تولیدی شُل نشده است. این اصلاح پیشگیرانه است، نه ادعای مشاهدهٔ خرابی TLS روی همهٔ گوشی‌های Android 14.

## شواهد فعلی، نه گواهی انتشار

مبنای کد اجرایی نهایی در این مرحله `7ab8ef3` است؛ نتیجهٔ نسخه‌های قدیمی به آن تعمیم داده نمی‌شود.

- آزمون محلی host و 25 تست ابزار انتشار موفق‌اند؛ مجموعهٔ refresh/dedup شامل 53 assertion موفق است.
- [34359856316](https://github.com/hojjatrad/parvaz/actions/runs/34359856316) و [34359856172](https://github.com/hojjatrad/parvaz/actions/runs/34359856172): کامپایل Android، تست‌های واحد و R8 روی `7ab8ef3` موفق.
- [34356644136](https://github.com/hojjatrad/parvaz/actions/runs/34356644136) روی `1a64dd5`: TCP و رد دسترسی بدون احراز هویت برای هر دو موتور روی Android 10/14؛ fixture میزبان HY2/TUIC با TCP/UDP، TLS سخت‌گیرانه، رد SNI نادرست و نبود fallback مستقیم؛ full-clash با گروه/مسیریابی و TCP/UDP موفق.
- [34353616609](https://github.com/hojjatrad/parvaz/actions/runs/34353616609): پروب Android 10/14 امضای آرشیو و Keystore موفق؛ این پروب اتصال کامل VPN نیست.
- [34357616744](https://github.com/hojjatrad/parvaz/actions/runs/34357616744) روی `26e1ac6`: کلید دائمی، lint، واحدها، ساخت امضاشده، package/version/hash و بسته‌بندی native موفق؛ سورس متناظر 477,391,576 بایت. این نتیجه پیش از اصلاح CA و آزمون‌های تازه است.
- [34359855616](https://github.com/hojjatrad/parvaz/actions/runs/34359855616): آزمون native روی `7ab8ef3` موفق: هر دو موتور روی شبیه‌ساز x86_64 با API 29/34 راه‌اندازی و احراز هویت شدند؛ HY2/TUIC تبادل واقعی TCP/UDP و مسدودماندن پس از قطع سرور را گذراندند. ساخت بستهٔ CA از TrustManager نیز در این نشست‌های واقعی اجرا شد. تست‌های سخت‌گیرانهٔ TLS/SNI و مسیرهای full-clash روی میزبان مجدداً موفق بودند. گواهی fixture خودامضا و opt-out فقط آزمایشی است؛ موفقیت آن اثبات TLS سخت‌گیرانه روی Android نیست.
- [34359856376](https://github.com/hojjatrad/parvaz/actions/runs/34359856376): اعتبارسنجی ساخت امضاشدهٔ `7ab8ef3` موفق؛ lintDebug/lintRelease، واحدها، کلید دائمی، APKهای امضاشده، package/version/hash، سقف حجم و تطابق/alignment هسته‌ها گذشتند. سورس متناظر 477,391,929 بایت ساخته شد.
- سقف APK برابر 128 MiB، ELF PT_LOAD هسته‌های تازه با alignment شانزده KiB، امضای دائمی و تطابق فایل با native ساخته‌شده همچنان شرط انتشارند. کنترل alignment به معنی آزمون نصب روی دستگاه واقعیِ 16 KiB نیست.
- نسخهٔ 1.26 تا عبور از دروازه‌های انتشار نباید به‌عنوان آپدیت پایدار معرفی شود.

## محدودیت‌هایی که باید روشن بمانند

پیکربندی کامل فقط از منبع قابل‌اعتماد وارد شود. قواعد DIRECT صریح حفظ می‌شوند. listener/TUN و مدیریت رابط را Android/پرواز کنترل می‌کنند؛ سیاست‌های وابسته به فرایند و رابط دسکتاپ معادل‌سازی نمی‌شوند. fake-IP میهومو برای این مسیر به پاسخ IP واقعی تبدیل می‌شود. سرویس‌های مدیریتی/اجرایی حذف یا رد می‌شوند.

قبل از ارتقا پشتیبان رمزدار بگیرید. حذف برنامه/داده می‌تواند کلید دستگاه را از بین ببرد؛ این کلید با کلید امضای انتشار فرق دارد. خروجیِ در حال انتخاب مقصد در حافظه است؛ اگر Activity بازسازی شود و خروجی از دست برود، ذخیره موفق اعلام نمی‌شود و باید دوباره خروجی گرفت. بازیابی رکوردها و تنظیمات دو commit جدا دارند؛ ادعای تراکنش چندفایلی نداریم.

هنوز آزمون گوشی واقعی، ارتقای درجا، پنل‌های خصوصی، قطع ناگهانی فرایند، جابه‌جایی Wi-Fi/mobile، Doze/باتری، Kill Switch و نشت واقعی انجام نشده است. نتیجهٔ شبیه‌ساز یا fixture جای آن‌ها را نمی‌گیرد. بدون این شواهد نباید «همهٔ دستگاه‌ها و همهٔ پنل‌ها تضمین‌شده‌اند» گفته شود.
