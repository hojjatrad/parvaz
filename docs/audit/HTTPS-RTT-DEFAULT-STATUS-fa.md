# پینگ HTTPS و آخرین اتصال پیش‌فرض — ۱٫۲۸٫۵

## معیار و اصلاح

عدد قبلی کل پاسخ HTTPS شامل مذاکرهٔ پراکسی/TLS را اندازه می‌گرفت و تست دستی بزرگ‌ترِ دو نمونه را نشان می‌داد. این لزوماً عدد جعلی نبود، اما با RTT درخواست آماده هم‌معنا نبود. اکنون EventListener زمان requestHeadersStart تا responseHeadersEnd را با ساعت monotonic اندازه می‌گیرد. تست دستی میانهٔ سه پاسخ 2xx معتبر را نشان می‌دهد؛ تأیید اتصال و سلامت یک پاسخ با همان واحد دارند. زمان صف، راه‌اندازی هسته، TCP، CONNECT و TLS خارج از پنجره‌اند. این عدد ICMP، تأخیر مستقل DNS، زمان کامل وصل‌شدن، سرعت دانلود یا تضمین عملکرد نیست؛ پردازش مقصد HTTPS نیز داخل آن است.

پراکسی HTTP به loopback مشخص مقید است؛ fallback مستقیم، redirect، retry خودکار انتقال و تضعیف TLS/نام میزبان وجود ندارد. نمونهٔ ناموفق با عدد ساختگی جایگزین نمی‌شود. زمان‌پایان، خطای TLS، پاسخ HTTP نامعتبر، خطای شبکه، لغو و اشغال ظرفیت وضعیت جدا دارند؛ اشغال محلی در پایش خودکار شکست سلامت محسوب نمی‌شود. cache و متوسط/نوسان تأخیر قدیمی با معیار جدید ادغام نمی‌شوند، اما پروفایل‌ها و شمارنده‌های تاریخچه حذف نمی‌شوند.

تست کانکشن فعال از listener مقید همان هستهٔ زنده استفاده می‌کند. lease به نشست، شبکه، resolver و هنگام گرفتن آن به شناسه/منبع/fingerprint وابسته است. برای سایر کانکشن‌ها مسیر ایزولهٔ هستهٔ واقعی باقی است؛ این به معنی اثبات همزیستی روی گوشی نیست. ردیف همسان پس از refresh به نمونهٔ فعلی متصل می‌شود و نتیجهٔ ویرایش‌شده/بایگانی‌شده پذیرفته نمی‌شود. رنگ ردیف همچنان کمتر از 300 سبز، 300 تا 799 زرد و از 800 قرمز است؛ دکمهٔ اصلی فقط با مدرک تازهٔ ارتباط سبز می‌شود.

## پیش‌فرض

last_verified_connection از selected_profile جداست و فقط مدرک تازهٔ اتصال زنده آن را ثبت می‌کند. لمس ردیف، تست دستی، RX یا شروع محلی کافی نیست. تیک موجود آمار و مسیر توقف/جایگزینی هسته، پیش از از بین رفتن مدرک آن را ذخیره می‌کنند؛ مدرک تازه‌ای که هنوز به تیک UI نرسیده نیز گم نمی‌شود. قفل manager → store → diagnostics حفظ شده؛ callback زیر قفل monitor وارد manager نمی‌شود. اعتبار منبع، نمونهٔ فعلی، fingerprint، نشست، شبکه و resolver قبل از ذخیره کنترل می‌شود.

در شروع سرد، توقف/شکست، بوت، tile و always-on آخرین مورد معتبر بازیابی می‌شود. انتخاب موقت داخل همان نشست و چرخش صفحه بازنویسی نمی‌شود. اتصال حذف/ویرایش‌شده یا خارج از منبع فعال احیا نمی‌شود. مارکر در پشتیبان رمزدار حمل می‌شود؛ بازیابی پشتیبان قدیمی مارکر محلی نامرتبط را پاک می‌کند. تأیید اتصال در نسخهٔ جدید این سابقه را می‌سازد؛ از تاریخچهٔ تست دستی، اتصال موفق گذشته حدس زده نمی‌شود.

## محدودیت و ارتقا

نسخهٔ نصب‌شده، کانفیگ خصوصی و بازتولید روی گوشی در دسترس نبود. نصب، VPN زنده در کنار probe سایر ردیف‌ها، نشت DNS/IPv6، Kill Switch، Doze، handover و باتری روی سخت‌افزار NOT_RUN هستند. برای سایر کانکشن‌ها تست تکی/گروهی لازم است؛ خودکار تنها ردیف تست‌نشدهٔ اتصال زندهٔ دارای مدرک پر می‌شود. مسیر کاملِ مبهم، کانفیگ پشتیبانی‌نشده یا سرور بی‌پاسخ تضمین پینگ عددی ندارد. DNS آزمایشگاهی وارد عملکرد APK نشده و flush درجا/انتقال TTL کامل نیست. تغییر عدد، تضمین افزایش سرعت واقعی نیست. پیش از ارتقا پشتیبان رمزدار بگیرید؛ برنامه و داده‌ها را پاک نکنید.
