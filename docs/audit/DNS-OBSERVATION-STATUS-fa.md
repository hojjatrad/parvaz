# وضعیت پیوستگی تشخیص DNS در ۱٫۲۸٫۲

نسخهٔ stable، APKهای عمومی، سورس، هش‌ها، امضای ثابت و latest مستقل بررسی شدند. شواهد در `docs/releases/v1.28.2-verification.json` ثبت شده است.

مشخصات DNS پس از برگشت همان شبکه دوباره خوانده می‌شوند. snapshot دیررس پس از فاصلهٔ نامشخص بی‌اثر نیست و نسل resolver را تغییر می‌دهد. snapshot ساختاریافته، ترتیب، scope و تفاوت null با دامنهٔ واقعی را حفظ می‌کند؛ نام نمایشی آدرس هویت resolver نیست.

پاک‌سازی درجا و انتقال TTL/cache پیاده نشده‌اند؛ کنترلر تازه‌ای باز نشده است. بازسازی محافظه‌کارانه ممکن است سوکت‌های باز را قطع کند. DNS timing، اولین پاسخ مستقل برنامه، تست گوشی، نشت، باتری و Doze تکمیل/تأیید نشده‌اند.
