# ممیزی تکمیل اصلاحات پرواز 1.25

**تاریخ:** ۹ سپتامبر ۲۰۲۶  
**دامنه:** تطبیق ۱۸ مورد گزارش اولیه با کد منتشرشدهٔ 1.25 و خواسته‌های بعدی کاربر.  
**منبع APK:** `15e892b014bd3261e242be27bc96321e9578d2cf`، package برابر `com.parvaz.tunnel`، versionCode برابر 26.

## نتیجهٔ صریح

**خیر؛ همهٔ ایرادهای اولیه رفع نشده‌اند.** اصلاحات دریافت/پردازش ساب، هویت و مالکیت اتصال، انتخاب گروه فعال، گزارش‌های خودکار و مسیر انتشار پیشرفت کرده‌اند و تست دارند. اما هات‌اسپات و منطق تست نشت هنوز ایراد مشخص دارند. چند قابلیت و آزمون دستگاه نیز باقی مانده‌اند. نتیجهٔ مشکل اخیر روی گوشی و ساب واقعی کاربر هنوز تأیید نشده است.

این ممیزی برنامه یا APK را تغییر نمی‌دهد و انتشار تازه‌ای ایجاد نمی‌کند.

## شواهد تازهٔ این بررسی

- اجرای مجدد `tools/audit/run.sh`: **304 assertion موفق**؛ شامل parser/builder، HTTP/TLS، store/refresh، import، قالب‌ها، مسیر شبکه و گروه‌بندی.
- اجرای مجدد تست‌های محافظ انتشار: **23 تست موفق**.
- بررسی XML منابع و manifest: موفق.
- آخرین انتشار عمومی در زمان بررسی: **v1.25**.
- هر دو APK عمومی مجدداً به‌صورت جریانی دریافت شدند؛ اندازه و SHA-256 آنها با `SHA256SUMS.txt` و مدرک انتشار مطابقت داشت. APK محلی نگه‌داری نشد.
- هستهٔ پین‌شدهٔ برنامه **v26.9.9** است؛ آخرین انتشار رسمی AndroidLibXrayLite نیز در این بررسی همین نسخه بود.
- وضعیت [validation Android/امضا](https://github.com/hojjatrad/parvaz/actions/runs/34340546505)، [انتشار](https://github.com/hojjatrad/parvaz/actions/runs/34341003767) و [بررسی API آپدیت](https://github.com/hojjatrad/parvaz/actions/runs/34341467328) مجدداً دیده شد: هر سه موفق. Android/Robolectric در این نوبت از نو اجرا نشده است.
- آزمایش مجزای منطق واقعی `LeakTester.Report` با دو نتیجهٔ UNKNOWN، مقدار `allPassed=true` داد. شبکه تماس داده نشد؛ IpLookup فقط جایگزین کامپایل بود. **این بازتولید یک ایراد باقی‌مانده است، نه تستِ اصلاح آن.**
- فایل‌های LeakTester، HotspotProxyManager، BackupCrypto و manifest محلی با فایل‌های tag منتشرشدهٔ v1.25 برابر بودند؛ یافته‌ها صرفاً متکی به گزارش قدیمی نیستند.
- فضای آزاد محیط کار **19.74 GiB**؛ ابزار محافظ فضا اجرا شد و پاک‌سازی اجباری لازم نبود.

## خواسته‌های بعدی کاربر

| خواسته | نتیجه |
|---|---|
| تشخیص خودکار لینک ساب | در مسیر افزودن معمولی پیاده و تست شده؛ ساب افزوده‌شده خودکار گروه فعال می‌شود. |
| کشیدن فهرست فقط برای همان ساب | مسیر Context دستی/خودکار به گروه فعال محدود شده؛ ورود دادهٔ منبع دیگر و تغییر هم‌زمان گروه تست دارد. **نتیجه روی گوشی واقعی کاربر هنوز بسته نشده است.** |
| زیادنشدن تکراری‌ها | پاسخ کامل معتبر جایگزین همان منبع و dedup می‌شود. پاسخ ناقص هنوز دادهٔ معتبر جدید را با قبلی ادغام می‌کند؛ در این حالت رشد تعداد ممکن است و برنامه آن را refresh کاملاً موفق حساب نمی‌کند. |
| عدم نمایش گزارش | پنجرهٔ گزارش خودکار در مسیرهای import/refresh/cleanup حذف و در UI تست شده است. خطا پیام کوتاه دارد؛ گزارش فقط با انتخاب خود کاربر باز می‌شود. |
| حجم واقعی و نبودن درصد ثابت | منبع صحیح و metadata سهمیه تست دارند؛ بدون دادهٔ پنل، مصرف واقعی قابل حدس نیست. |
| آپدیت با امضای ثابت | مسیر انتشار و بررسی package/version/hash/signature برقرار و latest عمومی تأیید شده؛ نصب نهایی به تأیید Android نیاز دارد و مسیر کامل روی گوشی کاربر هنوز مستقلاً آزمایش نشده است. |
| به‌روزبودن هسته | اکنون با آخرین نسخهٔ رسمی برابر است. workflow روزانه وجود دارد؛ آخرین اجرای دیده‌شدهٔ نگهداری، check-only بوده، نه اجرای کامل یک ارتقای آینده. تضمین «همیشه بدون خطا» داده نمی‌شود. |
| اندروید 10 به بالا | تست‌های Robolectric روی SDK 29 و 34 و پروب native قبلی امضای آرشیو وجود دارند؛ همهٔ دستگاه‌ها، نسخه‌های Android، اتصال واقعی، Kill Switch، DNS/IPv6 و مصرف باتری آزمایش نشده‌اند. |

## اولویت کار باقی‌مانده

1. **اولویت بالا:** اصلاح جمع‌بندی تست نشت و نمایش صریح «نامشخص»؛ اصلاح/ایمن‌سازی پل هات‌اسپات. تا آن زمان نتیجهٔ «بدون نشت» مدرک قطعی امنیت نیست و استفاده از اشتراک‌گذاری هات‌اسپات توصیه نمی‌شود. این یافته، اثبات وقوع نشت واقعی VPN نیست.
2. **تأیید مسئلهٔ اصلی کاربر:** آزمون فهرست و دو refresh پیاپیِ همان ساب در نسخهٔ نصب‌شده، سپس آزمون اتصال و ارتقای واقعی. بدون این مرحله نباید شکایت اخیر را قطعاً مختومه اعلام کرد.
3. **تکمیل محصول:** share/file/deep-link، سازگاری نسخه‌بندی‌شدهٔ بکاپ، حفاظت داده و دوام ذخیره‌سازی.
4. **نگهداری:** Wrapper/lint، بازنشسته‌کردن bootstrap قدیمی، خارج‌کردن آرشیوهای قدیمی از درخت سورس با بررسی بکاپ؛ بازنویسی تاریخچه فقط با اجازهٔ جداگانه.
5. **توسعهٔ قابلیت جداگانه:** اگر اتصال Hysteria2/TUIC یا اجرای کامل Sing-box/Clash لازم است، نیازمند تصمیم و پیاده‌سازی مستقل است؛ نام‌گذاری یا تبدیل ظاهری جای هستهٔ مناسب را نمی‌گیرد.
