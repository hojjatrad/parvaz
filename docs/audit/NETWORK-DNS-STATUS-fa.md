# وضعیت شبکه و DNS در ۱٫۲۸٫۰

نسخهٔ stable منتشر و هر دو APK عمومی، source، هش‌ها، گواهی ثابت و latest مستقل بررسی شدند. جزئیات در `docs/releases/v1.28.0-verification.json` است.

تأیید سلامت به revision شبکه و سیاست resolver وابسته است؛ RX جای مدرک HTTPS را نمی‌گیرد. مدرک دو دقیقه اعتبار دارد و تیک سلامت از حدود یک دقیقه درخواست تجدید می‌کند. تغییر شناخته‌شدهٔ سیاست DNS موجب بازسازی هسته می‌شود، نه انتقال کورکورانهٔ cache.

کپی cache بین موتورهای متفاوت، زمان مستقل DNS، آزمون گوشی، نشت، باتری و Doze انجام نشده‌اند. تغییر شبکه یا DNS می‌تواند ارتباط‌های باز را قطع کند. محدودیت‌های کامل در یادداشت نسخه آمده‌اند.

## شواهد و مرز اعتبار

- نسخه 1.28.0 / code 34؛ commit اجرایی `fc4f48ba62ba135a5b8710062adf6f3788e4d1e2`؛ 14 gate موفق، 366 آزمون واحد بدون failure/error/skip و 36 تست Python انتشار.
- سن مدرک با `elapsedRealtime` محاسبه می‌شود و خواب دستگاه را هم شامل می‌شود؛ اندازه‌گیری فازهای راه‌اندازی همچنان clock جدا دارد. آزمون خواب، ساعت مجازی است نه Doze روی گوشی واقعی.
- نوسان وضعیت اعتبارسنجی Private DNS با resolver ثابت، هسته را تخریب نمی‌کند. پس از تغییر هویت resolver، هستهٔ قبلی حتی با revision جدید نمی‌تواند تأیید صادر کند.
- [مرز cache و تحقیق روی APIهای upstream](DNS-CACHE-BOUNDARY-fa.md): کنترلر عمومی جدیدی باز نشده و انتقال TTL/cache یا flush درجا پیاده نشده است.
- نتیجهٔ عمومی APK، گواهی و latest در JSON انتشار ثبت شده؛ نصب روی گوشی، Kill Switch، نشت DNS/IPv6، جابه‌جایی شبکه و باتری همچنان NOT_RUN است.
- release ID، نام، حجم و digest فایل‌های نسخه‌های 1.26.4، 1.26.5 و 1.27.0 با شواهد قبلی تطبیق داده شدند؛ هیچ فایل انتشار قبلی جایگزین نشده است.
- زمان مستقل DNS/اولین پاسخ برنامه، حذف انتظار reconnect فعلی 300ms و هم‌زیستی native probe جداگانهٔ Xray با VPN فعال روی گوشی هنوز تکمیل/تأیید نشده‌اند.
