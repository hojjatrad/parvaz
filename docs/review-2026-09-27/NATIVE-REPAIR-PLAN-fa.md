# طرح رفع هدفمند وابستگی‌های Native

وضعیت: BLOCKED. دستور ادامه و نهایی‌کردن، لغو شرط عدم تحویل APK قبل از تکمیل شواهد نیست.

۱. حداقل نسخهٔ اصلاح‌شدهٔ هر هشدار از snapshot OSV ثبت‌شده تعیین شود؛ gRPC باید حداقل 1.83.2 باشد، نه 1.83.1. ارتقای فراگیر به latest یا downgrade نسخهٔ بالاتر ممنوع.
۲. روی سورس رسمی pinned دو هسته، تغییر go.mod/go.sum به‌عنوان patch مستند اعمال و نسخهٔ ساخته‌شده از upstream بدون تغییر متمایز شود. fork/replacement ناشناخته باید متوقف شود.
۳. ابتدا ساخت host و loopback protocol با همان سازندهٔ کانفیگ محصول؛ سپس ساخت واقعی Android هر دو ABI و ثبت فهرست بسته‌های کامپایل با هش همان باینری. تست host جای نصب یا ساخت ARM نیست.
۴. Xray AAR فعلی و هش‌هایش بدون اثبات سورس/ساخت جایگزین نمی‌شوند. باقی موارد آن همچنان مانع‌اند.
۵. مستقل از تغییر محصول، دو APK قبلی و کاندیدای ثابت روی تصویر رسمی API33 آزمایش راه‌اندازی شوند؛ بدون تغییر APK، TLS، SELinux یا متغیرهای runtime. این کنترل، هنوز آزمون مهاجرت/updater نیست. tombstone کامل برای علت‌یابی حفظ شود.
۶. هر تغییری فقط پس از آزمون و اسکن تازه وارد مسیر نهایی شود. کلید generation3 و انتشار stable قبلی دست‌نخورده می‌مانند.
