# Arena Universal Engineering Skills
مجموعه 23 فایل Skill برای ساخت و تعمیر نرم‌افزار با کیفیت Production.

پوشش:
- توسعه کاملاً ماژولار
- فارسی و RTL
- UI/UX مدرن و زیبا
- Responsive و Mobile-first برای موبایل، تبلت و دسکتاپ
- Accessibility
- تست Unit/Integration/API/E2E/Regression
- Security و Code Review
- Performance و Dependency Audit
- Deployment و Installer
- ممیزی و تعمیر پروژه‌های موجود
- مدیریت ایمن Workspace
- جلوگیری از ادعاهای بدون شواهد
- Final Release Gate

استفاده:
1. پوشه `arena` را در Workspace قرار دهید.
2. `00-MASTER-RULES.md` را Master/Global Rule قرار دهید.
3. برای پروژه موجود ابتدا `19-LEGACY-AUDITOR.md` را اجرا کنید.
4. قبل از Release، `18-FINAL-RELEASE-AUDITOR.md` را اجرا کنید.
5. برای هر پروژه در صورت نیاز `22-PROJECT-CONTEXT-TEMPLATE.md` را تکمیل کنید.

اصل کلیدی: Agent بدون شواهد کافی حق اعلام READY ندارد.
